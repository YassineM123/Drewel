# Drewel

A comprehensive CSS-focused project featuring reusable UI components and styling utilities for modern web applications.

## Features

- 🎨 Reusable CSS Components
- 📐 Responsive Design Patterns
- 🔧 Utility Classes
- 📱 Mobile-First Approach
- ⚡ Optimized Performance

## What's Included

- Component library with common UI patterns
- Responsive grid system
- Typography system
- Color palette utilities
- Animation utilities
- Layout components

## Installation

```bash
npm install drewel
```

## Usage

```html
<link rel="stylesheet" href="path/to/drewel.css">

<!-- Use components -->
<div class="container">
  <button class="btn btn-primary">Click Me</button>
</div>
```

## Tech Stack

- Pure CSS
- No Dependencies
- Fully Customizable
